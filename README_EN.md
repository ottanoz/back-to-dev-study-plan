# 🚀 Projects in this Study Plan

## **1. Dev Productivity Dashboard** (Frontend)
A modern dashboard focused on productivity.

**Tech stack:**  
React · Next.js · TypeScript · TailwindCSS · Zustand · React Query

**Features:**
- Weather widget  
- Tasks widget  
- Notes widget  
- Dark/Light theme  
- Global state with Zustand  
- Clean UI with Tailwind  

---

## **2. Mini ERP (Full Stack)**  
A complete stock management system integrating backend + frontend.

**Backend:**  
NestJS · Prisma · PostgreSQL · Docker · JWT · RBAC  

**Frontend:**  
Next.js · React Query · Tailwind

**Features:**
- Authentication (JWT + Refresh Tokens)  
- Role-based access (admin/user)  
- Products CRUD  
- Stock movement (in/out)  
- Protected routes  
- Production deployment (Railway + Vercel)
