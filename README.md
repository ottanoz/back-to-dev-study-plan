## 📘 Sobre este repositório

Este repositório documenta meu **plano estruturado de estudos** para voltar ao desenvolvimento moderno, recuperar fluência técnica, criar projetos de portfólio e me preparar para oportunidades internacionais.

# 🚀 Projetos do Plano

## **1. Dev Productivity Dashboard** (Frontend)

Uma aplicação web moderna para produtividade pessoal.

**Stack Tecnológico:**  
React · Next.js · TypeScript · TailwindCSS · Zustand · React Query

**Funcionalidades:**
- Widget de clima  
- Widget de tarefas  
- Widget de notas rápidas  
- Tema claro/escuro  
- Organização com Zustand  
- Design limpo e responsivo com Tailwind  

---

## **2. Mini ERP (Full Stack)**

Um sistema completo de estoque com backend robusto e frontend integrado.

**Backend:**  
NestJS · Prisma · PostgreSQL · Docker · JWT · RBAC  

**Frontend:**  
Next.js · React Query · TailwindCSS

**Funcionalidades:**
- Login (JWT + Refresh Token)  
- Controle de permissões (admin/user)  
- Cadastro de produtos  
- Movimentação de estoque (entrada/saída)  
- Rotas protegidas  
- Deploy profissional (Railway + Vercel)
